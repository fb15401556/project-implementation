# project-implementation
How to Run the Project
Open the notebook (Project_Implementation_Afaq Ahmed.ipynb) in Google Colab.
Enable GPU (Runtime → Change Runtime Type → T4 GPU).
Run all notebook cells sequentially from top to bottom.
The notebook will automatically:
Install required libraries.
Download and preprocess the AgXQA dataset.
Fine-tune the TinyLlama model using QLoRA.
Evaluate the model (BLEU, ROUGE, and BERTScore).
Save the trained model and results to Google Drive.
Use the final inference section to test the model with custom agricultural questions.
